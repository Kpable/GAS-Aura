# Aura RPG (Demo Project)

Aura RPG is a top-down **multiplayer action RPG** built in Unreal Engine, designed as a learning project to explore the **Gameplay Ability System (GAS)** and Unreal’s multiplayer framework.  
Players team up in 4-player co-op to explore dungeons, defeat enemies, and experience a fully attribute-driven combat system.  

---

## Project Overview
- **Top-Down RPG Gameplay** – explore dungeons, battle enemies, and grow stronger through combat.  
- **4-Player Co-Op Multiplayer** – built on Unreal’s networked gameplay framework, supporting synchronized abilities and combat interactions.  
- **Gameplay Ability System Integration** – abilities, damage, and effects are powered by GAS for scalable, data-driven design.  

---

## Key Features
- **Attribute-Driven Combat:** Armor, Resistances, Critical Hits, and Block mechanics handled via GAS execution calculations.  
- **Multiplayer Support:** Core systems designed with 4-player co-op in mind, ensuring consistent combat resolution across the network.  
- **Extensible Ability System:** Built around Unreal’s GAS to enable flexible character abilities and effects.  
- **Dungeon Exploration:** Players progress through encounters by defeating varied enemy types in dungeon environments.  
- **Data-Driven Scaling:** Character progression and combat balance influenced by curve-driven coefficients and captured attributes.  

---

## Technical Highlights
- **Unreal Engine C++ Development**  
- **Gameplay Ability System (GAS):** Execution calculations, attribute capture, and scalable combat logic.  
- **Multiplayer Networking:** Replication-aware combat and ability interactions across clients.  
- **Systems Programming:** Attribute-based calculations, curve scaling, and modular combat mechanics.  
- **Demo Project Purpose:** Serves as a sandbox for learning Unreal’s advanced systems and applying engineering best practices.  

---

## Skills Demonstrated
- C++ gameplay programming  
- Unreal Engine multiplayer and replication  
- Gameplay Ability System (GAS) design & integration  
- Attribute-driven, data-oriented systems  
- Cooperative action RPG mechanics  

---

## Status
This project is currently a **demo/learning project** and is not a full commercial game. Its primary focus is to explore Unreal’s Gameplay Ability System and multiplayer support while building a feature-complete RPG combat prototype.
